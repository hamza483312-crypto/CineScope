# CineScope 🎬

CineScope is a movie discovery project made using Python and the TMDB API. Users can search for movies and explore their details through a Streamlit web app.

## Features
- Search movies
- View movie details
- Get movie genres
- Extract and process movie data

## Tools Used
- Python
- Streamlit
- Pandas
- Matplotlib
- TMDB API

## How to Run

1. Clone this repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Create a `.env` file and add your TMDB access token:

```env
TMDB_ACCESS_TOKEN=your_token_here
```

4. Run the app:

```bash
streamlit run app.py
```
